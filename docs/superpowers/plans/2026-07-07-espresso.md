# Espresso Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust CLI named `espresso` that runs `caffeinate -dimsu -t <seconds>` until a user-supplied future local time, with a countdown progress bar and `q` early exit.

**Architecture:** Keep parsing and formatting testable in library modules. Keep terminal and process side effects in `main.rs`.

**Tech Stack:** Rust 2024, `chrono` for local time parsing, `crossterm` for raw-mode key input and line refresh, `anyhow` for CLI errors.
